# 알바 월급 계산기

출근한 날짜를 누르면 이번 달 월급이 자동으로 계산되는 웹앱(PWA)입니다.
기록은 **각자의 기기(브라우저)에만 저장**되고 서버로 전송되지 않습니다. 그래서 같은 링크를 여러 명이 써도 서로의 월급을 볼 수 없습니다.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `index.html` | 앱 본체 (화면 + 계산 로직 전부) |
| `manifest.webmanifest` | "홈 화면에 추가" 시 앱 이름·아이콘 |
| `sw.js` | 오프라인에서도 열리게 하는 서비스 워커 |
| `icon-*.png` | 앱 아이콘 |

## 무료로 배포하기 (링크 만들기)
사용자는 계정이 필요 없지만, 링크를 만들려면 무료 호스팅 계정이 **1개** 필요합니다.
개인 계정을 쓰고 싶지 않다면 이 앱 전용 이메일(예: 새 Gmail)을 하나 만들어 쓰세요.

### 방법 1. Netlify (가장 쉬움, 드래그 앤 드롭)
1. https://app.netlify.com/drop 접속
2. `alba-pay` 폴더를 통째로 끌어다 놓기
3. 앱 전용 이메일로 가입해 사이트를 저장(claim)하기. 저장하지 않으면 링크가 곧 사라집니다.
4. Site settings에서 사이트 이름을 바꾸면 `https://원하는이름.netlify.app` 같은 주소가 됩니다.
5. 수정본을 올릴 때는 Deploys 탭에 폴더를 다시 끌어다 놓으면 됩니다.

### 방법 2. GitHub Pages
1. 앱 전용 이메일로 GitHub 가입 → 새 저장소(Public) 생성
2. 이 폴더의 파일들을 업로드 (Add file → Upload files)
3. Settings → Pages → Branch를 `main`으로 지정 → 저장
4. 몇 분 뒤 `https://아이디.github.io/저장소이름/` 주소가 생깁니다.

> 주소는 반드시 `https://`여야 "홈 화면에 추가"와 오프라인 기능이 동작합니다. 위 두 방법 모두 자동으로 https입니다.

## 직원들에게 안내할 내용
1. 링크를 폰에서 열기
2. 홈 화면에 추가
   - **아이폰**: Safari로 열기 → 공유 버튼 → "홈 화면에 추가"
   - **안드로이드**: Chrome으로 열기 → ⋮ 메뉴 → "홈 화면에 추가" 또는 "앱 설치"
3. "알바·설정" 탭에서 학원, 알바 유형, 시급, 기본 근무시간 등록
4. "출근 달력"에서 출근한 날짜 누르기 → "이번 달 월급"에서 확인
5. **가끔 "백업 파일 저장"이나 "백업 코드 복사"를 해 두기.** 폰을 바꾸거나 브라우저 데이터를 지우면 기록이 사라집니다.

## 계산 기준
- **기본급**: 근무시간 × 시급. 출근·퇴근 시간에서 휴게시간을 뺍니다. 퇴근이 출근보다 이르면 자정을 넘긴 근무로 계산합니다.
- **주휴수당**: 월~일 한 주에 15시간 이상 일하면 `min(주 근무시간, 40) ÷ 40 × 8시간 × 시급`을 더합니다. 그 주의 **일요일이 속한 달**에 포함됩니다.
- **3.3% 공제**: 소득세 3%, 지방소득세(소득세의 10%)를 각각 10원 미만 버림으로 계산합니다.
- **공제율 직접 입력**: 4대보험 등 다른 공제는 비율(%)로 입력합니다.
- **최저시급 경고**: `index.html`의 `MIN_WAGE` 표를 기준으로 합니다. 새 해 최저시급이 발표되면 `2027: 금액` 줄을 추가하고, `sw.js`의 `CACHE` 버전 숫자를 올린 뒤 다시 배포하세요.
- **시급 변경**: 시급을 바꾸면 지난달까지의 기록에 기존 시급을 유지할지 물어봅니다.
